# Generic Stack Application using C++

## Description

This project implements a **generic stack data structure using C++ templates**. The program provides a reusable stack implementation that can work with different data types.

## Features

* Push elements into the stack
* Pop elements from the stack
* Display stack elements
* Create a new stack
* Continue using an existing stack
* Overflow and underflow handling
* Supports multiple data types

## Supported Data Types

* `int`
* `char`
* `float`
* `double`
* `string`

## Concepts Used

* C++ Classes and Objects
* Function Templates
* Stack Data Structure
* Arrays
* Switch-case
* Object Assignment

## Purpose

This project demonstrates how **C++ templates can be used to develop a reusable and flexible stack implementation for different data types**.
